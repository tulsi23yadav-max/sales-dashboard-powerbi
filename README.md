# 📊 Sales Performance Dashboard (MTD vs Last Year)

## 🔍 Project Overview
This Power BI dashboard analyzes sales performance by comparing Month-to-Date (MTD) results with the same period last year. It helps track growth, identify trends, and support business decision-making.

## 🛠 Tools Used
- Power BI  
- Excel  

## 📈 Key Insights
- Compared MTD sales with same period last year to measure growth  
- Identified increase/decrease in revenue and profit trends  
- Highlighted top-performing products and regions  
- Enabled dynamic filtering by time period and category
